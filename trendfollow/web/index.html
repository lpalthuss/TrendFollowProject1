오늘의 운용 순서

처음에는 계좌를 설정하고, 이후에는 같은 계좌로 2단계부터 진행하세요. 버튼을 누르기 전까지 수집·모의 처리는 실행되지 않습니다.

종가 처리 · 모의계좌 반영

실행 버튼을 누르면 확정 일봉으로 매매 조건을 판단하고 모의 체결·현금·보유 기록을 갱신합니다. 새 진입 신호는 다음 거래일 계획으로 저장합니다.

장중 관측 · 신호와 기록만

관측 ON 동안 돌파·거래량·산업 액션·손절 접촉을 판단합니다. 모의 체결을 실행하거나 계좌의 현금·보유를 바꾸지 않습니다.

장중 관측은 종가 처리를 대신하지 않습니다. 관측한 날에도 장마감 후 종가 처리를 별도로 실행하세요. 두 기능 모두 증권사 주문은 없으며, 정해진 시각의 예약 실행도 연결하지 않았습니다.

1. 사용할 계좌와 전략을 확인하세요

기존 계좌는 왼쪽에서 선택하세요. 새 전략을 비교하려면 아래에서 별도 계좌를 만드세요. 저장만으로 모의 처리가 시작되지는 않습니다.

새 계좌 만들기 · 전략 설정

설정으로 새 비교 계좌 만들기

기존 계좌 보존

기존 계좌의 설정은 바꾸지 않습니다. 저장하면 별도 설정과 미시작 계좌가 생깁니다. 최초 진입 방식의 우열을 미리 확정하지 않습니다.

전체 설정 직접 확인·편집

최대 거래 위험은 2% 이하입니다. 추가매수에는 셋업·검토·체결가 기준 초기 손절 설정이 필요합니다.

선택 계좌에 적용된 설정



선택한 계좌로 계속합니다. 설정은 화면 아래에 요약됩니다.


2. 자료를 준비하고 종가를 처리하세요
오른쪽 위 종가 기준일을 확인하세요. 당일은 16:10 이후 가능합니다. 처음 시작하는 계좌는 이 날짜를 출발점으로 삼으며 당일 장중 매수를 소급 처리하지 않습니다.
① 산업 자료 준비
② 가격 수집·대조·모의 처리
첫 종가 처리는 기준점만 만듭니다. 이후 처리에서는 이전에 저장한 진입 계획과 보유 종목의 조건을 모의 반영합니다. 새 신호가 나왔다고 이 버튼을 누른 시각에 즉시 매수하는 것은 아닙니다.
저장된 가격으로 개별 실행 · 고급
가격이 이미 준비된 경우만 사용하세요. 후보 재계산은 계좌를 변경하지 않습니다. 모의 처리 후 다시 실행할 필요는 없습니다.

4. 장중 관측은 선택 사항입니다
장마감 후에는 다음 관측일 계획만 준비하세요. 종가 결과 화면의 후보를 확인한 뒤 감시할 종목 코드를 입력합니다. 관측 ON은 해당 거래일 정규장에만 가능합니다. 종가 모의 처리는 관측 없이도 진행할 수 있습니다.
장중 관측 제어 · 모의 체결 없음
확인 중
잠정 돌파·산업 액션·거래량·손절 접촉만 관측·기록합니다. 신호가 발생해도 모의계좌를 변경하지 않습니다. 장마감 후 2단계 종가 처리를 별도로 실행해야 계좌 처리일이 진행됩니다.
관측이 끝나고 종가 데이터가 확보되면 같은 계획으로 결과를 대조합니다. 동시간 거래량은 유효 이력이 없으면 미확정입니다.
