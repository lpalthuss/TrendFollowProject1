종가 처리 · 모의계좌 반영

실행 버튼을 누르면 확정 일봉으로 매매 조건을 판단하고 모의 체결·현금·보유 기록을 갱신합니다. 새 진입 신호는 다음 거래일 계획으로 저장합니다.

장중 관측 · 신호와 기록만

관측 ON 동안 돌파·거래량·산업 액션·손절 접촉을 판단합니다. 모의 체결을 실행하거나 계좌의 현금·보유를 바꾸지 않습니다.

장중 관측은 종가 처리를 대신하지 않습니다. 관측한 날에도 장마감 후 종가 처리를 별도로 실행하세요. 두 기능 모두 증권사 주문은 없으며, 정해진 시각의 예약 실행도 연결하지 않았습니다.

4. 장중 관측은 선택 사항입니다

          

          

            애프터마켓 종료 후에는 다음 관측일 계획을 준비하세요. 종가 결과
            화면의 후보를 확인한 뒤 감시할 종목 코드를 입력합니다. 관측 ON은
            해당 거래일 정규장과 NXT 애프터마켓 거래 시간에 가능합니다. 종가
            모의 처리는 관측 없이도 진행할 수 있습니다.
          

          

            

              
장중 관측 제어 · 모의 체결 없음

              확인 중
            

            

              잠정 돌파·산업 액션·거래량·손절 접촉만 관측·기록합니다. 신호가
              발생해도 모의계좌를 변경하지 않습니다. 장마감 후 2단계 종가 처리를
              별도로 실행해야 계좌 처리일이 진행됩니다.

                없거나 연결이 끊겼으면 판단을 보류합니다. 확정 종가·모의계좌
                자료가 아닙니다.
